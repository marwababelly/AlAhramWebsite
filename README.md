# AlAhramWebsite
# موقع شركة الأهرام يوسف ملحم

## التشغيل
1. ثبّت Node.js (الإصدار 18 أو أحدث).
2. فك ضغط المشروع وافتح المجلد في VS Code.
3. افتح Terminal ونفّذ:
   npm install
   npm run dev
4. افتح رابط localhost الذي يظهر في الطرفية.

## أهم الملفات
- src/App.jsx: محتوى الموقع والأقسام والبيانات.
- src/styles.css: الألوان والتصميم والاستجابة للشاشات.
- index.html: اللغة العربية واتجاه RTL والخط.

## تحديث البيانات الوهمية
في أعلى ملف `src/App.jsx` ستجد الكائن `company`:
- phone: رقم الهاتف.
- whatsapp: رقم واتساب مع رمز الدولة دون + أو مسافات.
- email: البريد الإلكتروني.
- address: العنوان.

لتغيير الصور، استبدل روابط الصور الموجودة في مصفوفتي `services` و`gallery` وروابط صور الأقسام داخل JSX.

## ملاحظات قبل التسليم
- الصور الحالية توضيحية من Unsplash وليست صوراً للشركة.
- معلومات التواصل تجريبية ويجب استبدالها بالمعلومات الرسمية.
- أزرار فيسبوك وإنستغرام روابط شكلية حتى إضافة الحسابات الرسمية.
- الفيديو حالياً مساحة مخصصة لإضافة الفيديو التعريفي عند استلامه.
- راجعي الأرقام والمعلومات مع الشركة قبل النشر النهائي.
