# AlAhramWebsite
# موقع شركة الأهرام يوسف ملحم

## التشغيل
1. ثبّت Node.js (الإصدار 18 أو أحدث).
2. فك ضغط المشروع وافتح المجلد في VS Code.
3. افتح Terminal ونفّذ:
   npm install
   npm run dev
4. افتح رابط localhost الذي يظهر في الطرفية.

## أهم الملفات
- src/App.jsx: محتوى الموقع والأقسام والبيانات.
- src/styles.css: الألوان والتصميم والاستجابة للشاشات.
- index.html: اللغة العربية واتجاه RTL والخط.
